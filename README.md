# Photodiode Event Detection

Python signal-processing pipeline developed for neuroengineering research.

The pipeline detects photodiode state transitions from electrophysiological
recordings using filtering, smoothing, thresholding, and event detection.

It also supports batch processing and comparison against reference photodiode
states to evaluate detection accuracy.

Research datasets and generated outputs are excluded from this repository.
